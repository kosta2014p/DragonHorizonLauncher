# DragonHorizonLauncher

DragonHorizonLauncher — десктопный лаунчер для Minecraft-пакета DragonHorizon, созданный как гибрид Python + веб-интерфейс. Он позволяет запускать игру, автоматически обновлять сборку, управлять настройками Java/RAM, работать со скинами, ресурс-паками, шейдерами и следить за состоянием сервера.

## Возможности

- Запуск Minecraft с выбранным профилем и настройками
- Автоматическая проверка и загрузка обновлений сборки
- Настройка памяти (RAM), параметров Java и JVM-аргументов
- Поддержка тем, компактного режима и минимизации в трей
- Поддержка кастомных скинов, плащей, ресурс-паков и шейдеров
- Встроенная консоль логов лаунчера и игры
- Диагностика системы и восстановление сборки при проблемах
- Проверка состояния сервера и мониторинг игровой сессии
- Вход и работа с аккаунтом через внутреннюю авторизацию

## Стек

- Python
- pywebview
- HTML/CSS/JavaScript
- GitHub Releases для обновлений

## Требования

- Python 3.10+ (рекомендуется 3.11/3.12)
- Java, совместимая с версией Minecraft/сборки (обычно Java 17+ для современных сборок)
- Windows 10/11 (проект ориентирован на десктопный запуск под Windows)

## Установка

1. Склонируйте репозиторий:

```bash
git clone https://github.com/kosta2014p/DragonHorizonLauncher.git
cd DragonHorizonLauncher
```

2. Установите зависимости:

```bash
pip install pywebview
```

Если в проекте будут добавлены дополнительные зависимости, установите их по мере необходимости.

3. Запустите лаунчер:

```bash
python launcher.py
```

## Использование

После запуска откроется окно лаунчера, где можно:

- ввести никнейм;
- проверить актуальность сборки;
- настроить RAM и Java;
- выбрать дополнительные параметры запуска;
- открыть вкладки с настройками, скинами, ресурс-паками и шейдерами;
- запустить Minecraft или выполнить полную диагностику.

## Возможные сценарии

- Первый запуск: лаунчер может предложить базовую настройку и вход в аккаунт.
- Обновление: проект проверяет доступные версии и скачивает необходимые файлы.
- Исправление сборки: в случае проблем можно запустить ремонт/перекачку модпака.
- Диагностика: лаунчер позволяет проверить систему и локальные файлы игры.

## Разработка

Для разработки и доработки UI можно редактировать файлы в папке `web/`, а основную логику — в `launcher.py`.
